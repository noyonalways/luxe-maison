## ADDED Requirements

### Requirement: Sensitive Path Probing Interception
The server SHALL intercept requests attempting to access sensitive system files, environment configurations, version control artifacts, backup dumps, or script probe paths.

#### Scenario: Intercepting environment file probe
- **WHEN** a client sends a request targeting `.env`, `.env.production`, `.env.bak`, `config/.env`, or similar environment file variants
- **THEN** the request shield middleware SHALL immediately terminate the request and return HTTP status 403 Forbidden without executing downstream route handlers

#### Scenario: Intercepting credentials or backup file probe
- **WHEN** a client sends a request targeting sensitive file patterns like `service-account.json`, `credentials.json`, `id_rsa`, `*.sql`, `phpinfo.php`, `wp-admin`, or `.git/HEAD`
- **THEN** the request shield middleware SHALL immediately reject the request with HTTP status 403 Forbidden

### Requirement: Automatic IP Banning for Repeat Probing
The server SHALL track probe attempts per client IP address and apply a temporary ban when violation thresholds are exceeded.

#### Scenario: Client IP exceeds probe violation threshold
- **WHEN** a single client IP generates more than the allowed probe violation attempts (default: 5 violations within 10 minutes)
- **THEN** the server SHALL record the IP in an active IP ban list for a duration (default: 1 hour)

#### Scenario: Request received from banned IP address
- **WHEN** any HTTP request is received from an IP address currently in the active IP ban list
- **THEN** the server SHALL immediately reject all incoming requests from that IP with HTTP status 403 Forbidden without evaluating further routing or logic

### Requirement: Security Response Headers Enforcement
The server SHALL apply standard HTTP security headers to all outgoing server responses to mitigate common web security vulnerabilities.

#### Scenario: Injecting HTTP security headers
- **WHEN** any HTTP response is generated by the server
- **THEN** the response headers SHALL include `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `X-XSS-Protection: 1; mode=block`, and `Referrer-Policy: strict-origin-when-cross-origin`
